# Assets

Historical references inform the design language; they are not an asset library.

Do not add copyrighted historical logos, photographs, proprietary smiley packs, or exact branded interface graphics unless their reuse rights are clear.

Prefer original or freely licensed assets for generated examples. For forum messenger-style smilies, use an original/free raster set inspired by the visual language of ICQ/QIP-era messengers rather than bundling proprietary originals.
